Sources of the typing game's letter statistics and practice words
================================================================

Read by tools/make-typing-data.py, which writes public/typing/stats.json and
public/typing/words.json. All retrieved on 2026-11-23 (UTC) with curl. The
keyboard files in this folder have their own record, keyboards-SOURCES.txt.

Fetched by the script into cache/ (not kept in the repository)
--------------------------------------------------------------

The four files below were first kept in this folder and were then moved to
cache/, which git ignores: they are large, the subtitles list holds words
that do not belong in this repository, and the Quran files are needed only
for counting. tools/make-typing-data.py downloads each again when it is
missing, from the address given, and the checksums below let it be checked.
