Letter strokes

Admin tool, not linked from the site. The gray letter is drawn exactly as the child's tracing board will draw it. Draw each stroke on it in the order and direction the child should follow: drag for a stroke, tap for a dot. A green dot marks each stroke's start and an arrow its end. Replay shows the result the way the child will see it. When the letters are done, Write to folder and choose the public/tracing folder of the repo (Chrome or Edge on a computer), or Download the file and put it there.
