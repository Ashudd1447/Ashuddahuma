Kareem's tools, unlocked for this browser session. Nothing here changes the live site: the tools write files on this computer, which then go into the repo and get deployed.

  • Record audio
    Every clip the site plays, with the Egyptian version beside the Fusha one where both exist. Writes WAV files into public/audio.
  • Time the words
    Tap along a recording so the words light up as they are read. Writes public/audio/<surah>.timings.json.
  • Draw letter strokes
    The strokes the tracing lesson will check, drawn on the Naskh letters. Writes public/tracing/strokes.json.
