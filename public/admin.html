Kareem's tools. Nothing here changes the live site: the tools write files on this computer, which then go into the repo and get deployed.

  • Record audio
    Every clip the site plays, with the Egyptian version beside the Fusha one where both exist. Writes WAV files into public/audio.
  • Check the word timing
    The words light up automatically from each recording; preview an ayah here and tap along only when the automatic timing is off. Writes public/audio/<surah>.timings.json.
  • Draw letter strokes
    The strokes the tracing lesson will check, drawn on the Naskh letters. Writes public/tracing/strokes.json.
